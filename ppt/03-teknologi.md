# Slide 3: TEKNOLOGI

---

## **TEKNOLOGI — Apa yang Kami Gunakan?**

---

### 🎨 UI/UX Designer

| Teknologi | Kegunaan |
|-----------|----------|
| **Figma** | Perancangan wireframe, mockup, dan prototyping |
| **Design System** | Konsistensi visual: warna, tipografi, spacing, komponen |
| **Lucide Icons** | Ikon konsisten di seluruh antarmuka |
| **Font: Cormorant Garamond + Inter** | Heading elegan + body text modern |

> **Prinsip:** Konsistensi visual, aksesibilitas, dan responsive di semua perangkat.

---

### 💻 Frontend Developer

| Teknologi | Kegunaan |
|-----------|----------|
| **React 19** | Framework UI modern dengan komponen reusable |
| **TypeScript** | Type safety untuk kode yang lebih reliable |
| **Vite 8** | Build tool cepat untuk development & production |
| **Custom Hash Routing** | Navigasi tanpa library external |
| **Lazy Loading** | Code splitting untuk performa optimal |
| **Dual Data Source** | Mode API + Local (demo tanpa backend) |

> **Prinsip:** Performa cepat, modular, dan bisa berjalan offline/demo mode.

---

### ⚙️ Backend Developer

| Teknologi | Kegunaan |
|-----------|----------|
| **Node.js 22** | Runtime JavaScript untuk server |
| **Express 5** | Framework web untuk REST API |
| **JWT (Access + Refresh Token)** | Autentikasi aman dual-token |
| **Midtrans** | Payment gateway (Bank Transfer, QRIS) |
| **SSE (Server-Sent Events)** | Real-time updates untuk admin |
| **Rate Limiting + Helmet** | Proteksi dari serangan brute force & XSS |

> **Prinsip:** Keamanan, performa, dan API yang terstruktur.

---

### 🗄️ Database Engineer

| Teknologi | Kegunaan |
|-----------|----------|
| **MySQL (InnoDB)** | Database relasional untuk semua data |
| **35+ Tabel** | Struktur data terintegrasi |
| **UUID (VARCHAR 36)** | Primary key portabel tanpa auto-increment |
| **Foreign Keys** | Integritas data antar tabel |
| **JSON Columns** | Flexible data untuk field yang bervariasi |
| **Parameterized Queries** | Proteksi SQL injection |

> **Prinsip:** Integritas data, performa query, dan skalabilitas.

---

> *"Setiap teknologi dipilih berdasarkan kebutuhan nyata project, bukan sekadar trending."*
